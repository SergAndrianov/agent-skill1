# Ошибки и проверка исправлений

## SEARCH-1 · Вход повторного просмотра не виден

- **Наблюдение.** На связи клиента показан только ввод счёта. Выбор сохранённой привязки отсутствовал. [Первый прогон](artifacts/scrum-2163-initial-check.md)
- **Правило и последствие.** BR-07, SCRUM-2165 № 3. Повторный путь без ручного ввода нельзя проследить.
- **Изменение.** Добавить выбор сохранённого объекта на пользовательскую связь. Правило перенесено в шаг 2 SKILL.md.
- **Проверка.** Проверено по новому артефакту. [Результат](artifacts/scrum-2163-rerun-check.md)

## SEARCH-2 · Запись смешана с запросами

- **Наблюдение.** Поиск, чтение и подтверждение объединены на одной связи приложения с API. [Первый прогон](artifacts/scrum-2163-initial-check.md)
- **Правило и последствие.** BR-05 и BR-06 требуют явно выделить операцию, которая создаёт состояние.
- **Изменение.** Разделить команду сохранения и запросы. Указать доверенный ID поиска и результат команды. Правило внесено в шаг 2 SKILL.md.
- **Проверка.** Проверено по новому артефакту. [Результат](artifacts/scrum-2163-rerun-check.md)

## STACK-1 · Внутренний стек не имел источника

- **Наблюдение.** В исходной модели появились iOS/Android, Java/Spring Boot, PostgreSQL и внутренние протоколы. В knowledge этот выбор не был зафиксирован. [Первый прогон](artifacts/scrum-2163-initial-check.md)
- **Правило и последствие.** В AGENTS.md источниками требований определены Jira и knowledge. Читателю не видно, какие технологии выбраны для модели.
- **Изменение.** Зафиксировать технологические параметры как проектное допущение A-14. Привязку выбора к источнику включить в шаг 4 SKILL.md.
- **Проверка.** Проверено по новому артефакту. [Результат](artifacts/scrum-2163-rerun-check.md)

## LOAD-1 · Выбор API и БД без расчёта нагрузки

- **Правило и последствие.** Обоснование контейнерной модели должно объяснять границу ответственности и масштабирование. Из исходной модели их нельзя проверить количественно.
- **Изменение.** Добавить A-15 и расчёт пикового потока. В шаге 5 SKILL.md закреплена проверка нагрузочных предположений.
- **Проверка.** Проверено по новому артефакту. [Результат](artifacts/scrum-2163-rerun-check.md)

## PAY-1 · Условная интеграция показана как назначенная

- **Наблюдение.** В одной связи процессинг выглядит владельцем проверок инструмента и средств, а также источником статуса. [Первый прогон](artifacts/scrum-2166-initial-check.md)
- **Правило и последствие.** BR-09 и BR-12 задают проверку, Q-06 оставляет её контракт открытым. Назначение владельца не подтверждено.
- **Изменение.** Показать предварительную проверку отдельной условной связью. В шаге 4 SKILL.md закреплена маркировка условности на связи.
- **Проверка.** Проверено по новому артефакту. [Результат](artifacts/scrum-2166-rerun-check.md)

## PAY-2 · В платёжной команде не указан объект

- **Наблюдение.** Исходная подпись перечисляет ключ, сумму и источник списания без ID начисления. [Первый прогон](artifacts/scrum-2166-initial-check.md)
- **Правило и последствие.** BR-13 и BR-15 ограничивают платёж конкретным начислением. Ключ сверки и объект оплаты имеют разные назначения.
- **Изменение.** Указать в платёжной команде ID начисления, инструмент и сохранённый ключ. Сверку ролей идентификаторов добавить в шаг 2 SKILL.md.
- **Проверка.** Проверено по новому артефакту. [Результат](artifacts/scrum-2166-rerun-check.md)

## PAY-3 · Не виден запрос статуса до внешнего ID

- **Наблюдение.** В исходной подписи указаны два идентификатора без условия выбора. [Первый прогон](artifacts/scrum-2166-initial-check.md)
- **Правило и последствие.** BR-17 и A-09 требуют сверки исходной попытки после потери ответа. В этот момент внешний ID может отсутствовать.
- **Изменение.** Показать чтение по ключу, сохранённому до отправки, и зависимость от внешнего контракта. Сценарий закреплён в шаге 3 SKILL.md.
- **Проверка.** Проверено по новому артефакту. [Результат](artifacts/scrum-2166-rerun-check.md)

## PAY-4 · Фоновая работа привязана к API без владельца запуска

- **Наблюдение.** Обработка и сверка помещены в API, а распределение фоновых задач между экземплярами осталось открытым. [Первый прогон](artifacts/scrum-2166-initial-check.md)
- **Правило и последствие.** BR-11 и BR-15 требуют корректного отключения и защиты от дублей. Из исходной модели не видно, кто получает право отправить команду.
- **Изменение.** Добавить самостоятельно запускаемый обработчик по A-17. Задачи, захват, право отправки и сверка описаны в обосновании. Шаги 1 и 3 SKILL.md требуют показать владельца запуска и поведение при сбое.
- **Проверка.** Проверено по новому артефакту. [Результат](artifacts/scrum-2166-rerun-check.md)
